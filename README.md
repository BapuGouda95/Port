# Java Full-Stack Developer Portfolio

A responsive, modern dark-themed portfolio built with plain HTML, CSS, and JavaScript. No build tools or paid services are required.

## Files
- `index.html` — portfolio content and sections
- `style.css` — responsive styling and dark theme
- `script.js` — mobile navigation and current year
- `resume.pdf` — add your own resume PDF here before publishing

## Before publishing
Open `index.html` and replace:
- The education and About Me placeholder text

Review the ShopSphere feature description so it only claims features you have actually implemented. Add your resume as `resume.pdf`.

## Preview locally
Double-click `index.html` to open it in a browser. For a local server, open this folder in VS Code and use the Live Server extension.

## Publish for free with GitHub Pages
1. Create/sign in to GitHub and create a repository named `your-username.github.io` (or any repo if you plan to enable Pages from its settings).
2. Upload `index.html`, `style.css`, `script.js`, and `resume.pdf` (after adding it).
3. For a user-site repo named `your-username.github.io`, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for deployment. Your site will be available at `https://your-username.github.io/`.
5. Open the URL and test every link on desktop and mobile.

GitHub Pages serves static sites. This portfolio is static and does not need a backend.
